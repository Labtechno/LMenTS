LMenTS

Un module Eurorack modal émulé : son vrai firmware tourne dans une copie virtuelle de sa puce.

Cet installateur pose :

  • le plugin VST3, pour Reason ;
  • l'application LMenTS, pour jouer sans Reason.

S'il y a déjà une version de LMenTS, elle est remplacée. Ferme Reason avant de continuer.

Aucun firmware n'est fourni. Au premier lancement, charge le fichier de mise à jour officiel du module (par exemple elements_1.1.wav) ou un fichier .bin, avec le bouton « Charger un firmware… » ou en le déposant sur le plugin.
